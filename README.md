# Origen

Landing page estática para Origen, una marca de objetos hechos para durar.

La paleta visual está limitada a negro (`#000000`), café (`#251006`), blanco (`#FFFFFF`) y dorado (`#d4af37`). El logo proporcionado por la marca vive en `assets/logo-origen.png` y se usa en el hero, header, footer y favicon.

## Uso local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

## Enlaces sociales

Los cuatro perfiles sociales usan `href="#"` y están marcados como `data-placeholder="true"` en `index.html`. Sustituye cada `href` por la URL real del perfil correspondiente cuando esté disponible.
